## What is this!?

This is my creative portfolio, built with modern web tech, showcasing interactive experiences I've built and my experimental projects.

Think of it as my playground where you'll find all the things I've done and deem worthy to showcase...well most of them at least.

### Built With

- **React** + **Vite** - For that smooth, reactive experience
- **Three.js** + **@react-three/fiber** - 3D magic in the browser
- **@react-spring/three** + **GSAP** + **OGL** - Custom animations and WebGL effects
- **Tailwind CSS** - Styling without the hassle
- **Vercel** - Deployed with love
